# 微信小程序提交审核清单

- [ ] 小程序名称、头像、简介与实际服务一致

- [ ] 客服邮箱真实有效
- [ ] AppID 为正式 AppID
- [ ] 已关闭生产环境的本地数据回退
- [ ] 法律文档中的主体和联系方式已更新

## 服务类目与资质

- [ ] 按真实业务选择小程序服务类目
- [ ] 类目与页面功能一致
- [ ] 主体类型满足类目要求
- [ ] 摊主和运营方需要的经营许可已按实际情况准备
- [ ] 审核备注清楚说明“平台提供出摊信息发布、位置查找与导航，不提供在线交易”

## 隐私

- [ ] 公众平台《小程序用户隐私保护指引》已配置
- [ ] 位置信息用途与代码一致
- [ ] 图片、昵称、头像、摊位内容、关注和举报数据已如实说明
- [ ] 用户拒绝位置权限后仍可浏览基本列表
- [ ] 未在启动时强制申请不必要权限
- [ ] 隐私政策页面可正常打开

## 内容与用户生成内容

- [ ] 有内容安全检测
- [ ] 有人工审核入口
- [ ] 有举报入口
- [ ] 有发布规范
- [ ] 管理员可以驳回和处理举报
- [ ] 审核体验内容真实、完整、无敏感信息
- [ ] 页面中没有二维码、微信号、手机号和站外导流
- [ ] 图片版权清晰

## 审核备注参考

> 本小程序用于摊主发布本场出摊时间、地点和菜品信息，顾客可通过附近列表与地图查找并导航。小程序不提供在线支付、点餐、抽成或配送。用户发布内容经过文字安全检测和后台安全巡检；详情页提供举报入口。审核体验无需登录，请允许位置权限体验附近排序，也可拒绝权限浏览公开出摊信息。
