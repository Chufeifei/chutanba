# 本次 UI 优化说明

## 视觉升级

- 按参考图统一为暖米白、珊瑚橙、薄荷绿配色。
- 首页改为渐变信息卡、四宫格功能入口、横向卖点分类和悬浮胶囊底部导航。
- 主流程功能图标全部替换为本地线性插画图标，不依赖网络资源。
- 出摊卡片、详情页、个人中心、地图、收藏和运营审核页统一圆角、描边和图标语言。

## 卖点分类

预设以下分类：

饭团便当、早餐早点、面点小吃、粉面汤粥、烧烤炸物、熟食卤味、甜品烘焙、冰粉糖水、咖啡茶饮、水果鲜食、地方特色、手作零食、夜宵小炒、农产品、其他。

另提供“自定义”，摊主可以自由填写如“贵州糯米饭”“潮汕粿品”等品类。

## 摊主资料自动填写

摊主资料页新增：

- 默认本场名称
- 常卖品类与自定义品类
- 默认本场介绍
- 常用菜单
- 常用价格说明
- 常用公告
- 常用出摊地点

保存后，进入“发布出摊”会自动带入这些信息。发布页仍可针对本场单独修改，也可以点击“重新带入”恢复模板内容。

## 数据兼容

本地空数据模式和微信云开发模式都已同步升级。云端 `vendors` 数据会新增上述模板字段，旧数据可以继续读取。
