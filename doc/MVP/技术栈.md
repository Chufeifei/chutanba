# 技术栈

## 客户端

| 技术 | 用途与实现方式 |
| --- | --- |
| 微信原生小程序 | 使用 JavaScript 编写逻辑，WXML 编写页面结构，WXSS 编写样式，JSON 管理页面与组件配置。 |
| 微信云开发 SDK | 启动时通过 `wx.cloud.init` 初始化；通过 `wx.cloud.callContainer` 请求云托管服务。 |
| `wx.request` | 在本地联调配置下请求本地服务。 |
| 微信云存储 | 使用 `wx.cloud.uploadFile` 上传图片。 |

客户端的云环境、云托管服务名和本地联调地址集中在 `miniprogram/config/cloud.js` 配置。

## 服务端

| 技术 | 用途与实现方式 |
| --- | --- |
| Node.js `>=20` | 服务端运行时；代码使用 CommonJS 模块。 |
| Express 5 | 处理 HTTP 请求，使用中间件解析 JSON 和表单数据，并统一处理异常。 |
| `dotenv` | 从 `.env` 加载本地环境变量，配置由 `backend/src/config/env.js` 集中读取。 |
| `qrcode` | 生成二维码。 |

服务端依赖版本以 `backend/package.json` 为准，目前包括 Express `^5.2.1`、`dotenv` `^17.4.2` 和 `qrcode` `^1.5.4`。

## 数据库

- 使用 MySQL，连接字符集为 `utf8mb4`。
- 通过 `mysql2/promise` 创建连接池；当前依赖版本为 `^3.23.2`。
- 数据库连接参数、连接池大小及可选 TLS 由环境变量配置。

## 构建与运行

- 使用 Docker 构建服务端镜像，基础镜像为 `node:22-alpine`。
- 使用 `npm ci --omit=dev` 安装生产依赖，容器以非 root 的 `node` 用户运行。
- 服务端从环境变量读取 `PORT`；容器镜像默认端口为 `80`。
