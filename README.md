# 出摊吧｜微信小程序管理与关注提醒优化版 V4

“出摊吧”用于发布和查找流动摊位的出摊时间、地点、菜单与公告。项目采用微信原生小程序和微信云开发，保留暖米白、珊瑚橙、薄荷绿、圆角卡片与胶囊导航风格。

## V4 重点修复

- 正式版本默认开启云开发，个人中心显示微信云开发返回的真实 OpenID，不再显示 `local-user-openid`。
- 第一个进入小程序并完成云端身份初始化的用户自动成为超级管理员。
- 超级管理员可直接进入管理面板，粘贴其他用户的 OpenID 添加或移除运营管理员。
- 旧版 `admins` 集合已有管理员但没有超级管理员时，会自动将现有最早管理员升级为超级管理员。
- 关注逻辑从“关注某一场摊位”升级为“关注摊主”，摊主后续发布的新场次仍保持关注。
- 关注页自动展示每位已关注摊主当前或最近的一场有效出摊信息。
- 小程序处于前台时每分钟检查一次；关注的摊主开始出摊后自动弹框提醒。
- 小程序重新打开或从后台返回时也会立即检查提醒，同一场次不会反复弹窗。
- 配置订阅消息模板并取得用户授权后，小程序关闭时可通过微信一次性订阅消息提醒下一场出摊。
- 保留 V3 的发布按钮防连点、云端幂等、重复出摊合并、发布成功提示、地点选择和草稿保留修复。

## 直接导入

1. 解压 ZIP。
2. 微信开发者工具选择“导入项目”。
3. 选择解压后的项目目录：

```text
chutanba-miniprogram-fixed-v4
```

4. 替换为真实小程序 AppID，并绑定云开发环境。
5. `miniprogram/config.js` 已默认设置：

```js
USE_CLOUD: true
```

`CLOUD_ENV` 留空时使用开发者工具当前绑定的云环境，也可以填写指定环境 ID。

## 必须创建的数据库集合

```text
users

stalls
favorites
reports
subscriptions
admins
```

建议全部设置为客户端不可直接读写，仅允许云函数访问。

## 必须部署的云函数

右键以下目录，分别选择“上传并部署：云端安装依赖”：

```text
cloudfunctions/api
cloudfunctions/reminder
```

`api` 负责真实 OpenID、超级管理员、管理员维护、发布、关注和数据读取。

`reminder` 负责微信一次性订阅消息，定时触发器已调整为每分钟检查一次。暂不使用微信系统消息时可以先只部署 `api`，小程序内弹框提醒仍可使用。

## 超级管理员

无需手动填写第一位管理员：

1. 确保 `admins` 集合存在且为空。
2. 部署最新版 `api` 云函数。
3. 使用运营者微信首次打开小程序。
4. 进入“我的”，页面会显示真实 OpenID 和“超级管理员”标识。
5. 点击“超级管理面板”，在“管理员”页粘贴其他用户的 OpenID 即可添加运营管理员。

其他用户需要先打开一次小程序，然后在“我的”页面复制真实身份编号发给超级管理员。

## 关注提醒说明

### 小程序内弹框

不需要订阅消息模板。用户关注摊主后：

- 小程序在前台时，每分钟检查一次。
- 小程序从后台回到前台或重新打开时立即检查。
- 摊主处于有效出摊时间内时弹框，可直接进入摊位详情。
- 同一场出摊在同一设备上不会重复弹出。

### 微信系统订阅消息

需要在微信公众平台申请一次性订阅消息模板，并同时配置：

```text
miniprogram/config.js → REMINDER_TEMPLATE_ID
云函数 reminder → 环境变量 REMINDER_TEMPLATE_ID
```

推荐模板字段：

```text
thing1：摊位名称
time2：出摊时间
thing3：出摊地点
```

用户点击关注时会主动出现订阅授权。一次性订阅消息每次授权通常只对应下一次提醒，发送后需要用户再次授权才能继续接收后续系统通知。
